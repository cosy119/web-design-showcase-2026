# 2026 网页设计大赛作品展

在线访问：https://cosy119.github.io/web-design-showcase-2026/

首页仅保留作品截图、标题、作者姓名、学院、班级、分类筛选与搜索。点击作品在当前页面打开预览，可全屏或独立打开；关闭时卸载 iframe，停止作品音频及渲染。展示顺序不代表获奖排名。

分类按一等奖、二等奖、三等奖、参与奖展示。目前所有作品均为待评定，不预先授奖。评审后，在 works.json 中填写对应作品的 award 字段（仅支持上述四种奖项，null 表示待评定），再运行 `python scripts/update-awards.py` 同步首页奖项、筛选数量和搜索信息，提交后自动部署。

## 部署

GitHub Pages 采用 main 分支根目录发布，.nojekyll 禁用 Jekyll 处理。所有作品位于 works 下，引用资源使用相对路径。入口为 index.html，无需构建和后端服务。

## 来源及整理范围

活动目录的六件作品及待检查材料中的星签事务所已整理入站。保留作者原页面与运行所需资源；“驶向绿色未来”仅去除 DOCTYPE 前误留的 html 文本，“中国待客美食”入口更名为 index.html。

星签事务所的可读源码、Blender 与 GLB 模型保存在其 source、models 目录。原 Three.js 许可随源码保留。

未公开报名信息、学号、联系电话、活动检查清单和含个人资料的原投稿压缩包。食光计划的公开作品说明删除了学号行。本文作者信息来自投稿文件夹及主办方确认。
